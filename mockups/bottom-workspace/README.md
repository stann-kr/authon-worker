# Authon 전체 기능 목업

기존 서비스의 사용자 화면과 업무 흐름을 하단 메뉴 중심으로 재구성한 인터랙티브 목업입니다. 로그인·프로필부터 게스트 등록, 도어, 운영 관리와 통계까지 샘플 상태로 연결됩니다. [기능별 대응표](COVERAGE.md)에서 현재 제품의 근거와 목업 진입 경로를 확인할 수 있습니다.

## 열기

```sh
node mockups/bottom-workspace/build.mjs --serve
```

`http://127.0.0.1:4176`에서 열거나 생성된 `dist/index.html`을 직접 엽니다. HTML에 코드·스타일·QR 생성기를 포함하며 외부 CDN 없이 동작합니다. `--serve`를 빼면 파일만 생성합니다. 저장소에 설치된 의존성을 사용합니다.

## 검토 도구

- **역할 미리보기:** 관리자, SORA·MILO, 공용 운영팀, Door, 전체 관리자, 로그인과 외부 등록 화면을 전환합니다.
- **기능 목록:** 16개 기능 영역과 세부 항목을 확인하고 해당 목업을 바로 엽니다. 마지막 버튼으로 샘플 데이터를 초기화합니다.
- **검토 설정 → 목업 상태:** 로딩, 조회·저장 실패, 세션 만료, 오프라인·충돌, 링크 만료, 저장소 불가, QR 실패와 리포트 불일치 등을 해당 화면에서 확인합니다. 정상으로 되돌려 복구 흐름을 이어갑니다.
- **검토 설정 → KO / EN:** 화면 언어를 바꿉니다. 계정의 기본 언어는 프로필에서도 저장할 수 있습니다.
- **검토 설정 → 모바일 / 전체 폭:** 기본 400px 폭과 전체 폭을 전환합니다.

목업의 기준 운영일은 **2026-09-12**, 샘플 시각은 다음 날 00:18 KST입니다. 과거·미래 날짜와 일반 명단은 행사 선택에서 확인합니다. 새로고침하면 모든 변경이 초기화됩니다.

로그인 예시는 `sora@example.com` / `DemoPass123`입니다. 미설정 계정의 코드 흐름은 `invited@example.com` / `MOCK-INVITED`로 확인합니다. 모두 목업 전용 가상 값입니다. 재설정 승인용 4자리 확인번호는 사용자 요청 화면에서 확인한 뒤 관리자 화면에 입력합니다.

## 작업 화면과 사용성

제공된 React 코드와 이미지의 검정·무채색·초록·파랑을 기본으로 유지합니다. 배경 `#000000`, 시트 `#141414`, 버튼 `#1c1c1c`, 선택 상태 `#2a2a2a`, 보조 글자 `#8e8e93`, 초록 `#10b981`, 파랑 `#3b82f6`입니다. 초록색 주요 버튼에는 짙은 글자를 사용합니다.

- 베뉴·운영일·행사와 운영 상태를 화면 위에 유지합니다. 명단 통계는 명단 화면에서만 보여줍니다.
- 하단은 레퍼런스의 독립 pill 두 줄을 유지합니다. 윗줄은 아이콘과 이름이 가로로 놓이는 메뉴, 아랫줄은 원형 컬러 아이콘을 가진 작업 버튼입니다. 내용 너비에 따라 각 줄을 가로로 스크롤할 수 있으며 선택 상태는 회색 바탕으로 구분합니다. 필요한 요청은 메뉴 안에 건수를 표시합니다.
- 하단에 옅게 이어지는 배경 위로 pill을 배치합니다. 하단 영역의 실제 높이에 맞춰 목록 끝의 여백을 확보하고, 키보드 포커스 테두리를 위한 여백을 둡니다. 이 구조를 유지한 상태에서 검색·입력·복구 동작을 개선합니다.
- 명단 검색과 전체·미입장·입장 완료 필터는 목록을 스크롤해도 유지됩니다. 담당자·정렬 등 적용한 조건을 표시하고 개별 해제할 수 있습니다. 검색 결과가 없으면 검색·필터 초기화로 돌아갑니다.
- 더보기는 현장 운영 / 행사와 기록 / 계정과 설정으로 나누며 이름과 설명으로 검색할 수 있습니다. 역할별 접근 범위를 유지합니다.
- 단건·다중 등록 입력은 모드를 전환해도 각각 남아 있습니다. 중복 포함 승인은 모드를 전환하면 다시 확인합니다. CSV 안내는 실제로 불러오기 전의 상태를 구별합니다.
- 등록·계정·행사·링크·베뉴·RSVP 등 작성 시트에서 입력 후 닫기 또는 Escape를 누르면 계속 작성하거나 버릴 수 있습니다. 필터·조회 시트는 바로 닫힙니다. 입력 보존은 열린 시트 안에서만 동작하며 새로고침·탭 종료 후 복원은 제공하지 않습니다.
- 시트 제목·닫기와 폼 제출 영역을 유지하고, 모바일 가시 영역 변화에 맞춰 시트 높이를 조절합니다. 넓은 화면에서는 시트 폭을 제한해 긴 입력란을 줄입니다.
- 체크인 성공은 게스트 이름과 함께 알립니다. 실패 시 상세 화면과 재시도 버튼을 유지합니다. 입력 오류는 이름 필드에 연결합니다.

실제 브라우저의 시각·키보드·기기 동작은 아직 검증하지 않았습니다. DOM 검증은 상태 전환과 입력 보존 등의 동작을 확인하는 범위입니다.

## 구현 경계

이 폴더는 제품 route에 연결되지 않은 독립 목업입니다. `data/MockData.tsx`가 가상 데이터와 지연·실패 상태를 소유하고, 각 capability 폴더가 화면·입력·확인 동작을 소유합니다. 게스트/CSV 파싱, 계정 권한, 행사 상태 전환과 통계 기간·집계에는 기존의 순수 함수를 재사용합니다.

API·DB·실제 인증·메일·배포·도메인 변경을 수행하지 않습니다. 공유 링크, 영속 저장과 네트워크 오류는 모의 실행 범위를 따르며 상세 내용은 [대응표](COVERAGE.md)에 명시했습니다. 제품 적용과 실제 브라우저·기기 검증은 별도 단계입니다.
