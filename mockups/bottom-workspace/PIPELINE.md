# 아티스트 부킹 파이프라인 검토

2026-09-13 기준으로 기존 목업의 아티스트 → 부킹 → 일정 → 공연 준비 → 게스트/도어 연결을 검토했다. 아래 적용 내용은 샘플 메모리에서 동작하는 목업이다.

## 조사 근거

- [Artist Growth: Managing Event Logistics](https://help.artistgrowth.com/en/managing-event-logistics-help-center): 하나의 행사에서 일정·연락처·자료·게스트 목록을 연결한다. Authon에서는 별도 메뉴로 이동해도 같은 행사와 해당 아티스트 링크를 바로 열도록 적용했다.
- [Techrider: Show advance checklist](https://techrider.live/learn/tutorials/show-advance-checklist): 자료를 받는 단계와 현장 조건을 검토하는 단계를 구분하고, 교체 시간·담당자·미해결 업무·최신 자료 버전을 관리한다. 이를 근거로 운영팀 검토, 일정 여유 시간, 확인 필요 항목을 추가했다.
- [Prism: Shared Holds](https://prism.fm/shared-holds/): 홀드의 날짜와 우선순위 변경을 협업자 사이에 공유하면서 민감한 정보를 분리한다. 이번에는 기존 홀드 기한과 상대 확인 상태를 보강했다. 실제 외부 동기화가 되는 것으로 표현하지 않는다.

공급사의 기능 설명을 Authon 운영 현장에서 효과가 검증된 증거로 취급하지 않는다. 아래 우선순위는 기존 구현을 대조한 제품 설계 판단이다.

## 적용한 연결 보강

| 기존 빈틈 | 목업의 동작 | 확인 경로 |
| --- | --- | --- |
| 후속 기한·준비 누락을 각 화면에서 따로 찾아야 함 | 오늘까지의 후속 업무, 담당자/기한 누락, 홀드, 충돌, 상대 조정 요청, 자료·업무·링크 문제를 파생 상태로 계산 | 부킹 → 확인 필요 → 부킹 상세의 항목 선택 |
| 시간 변경 뒤 이전 가능 응답이 남음 | 일정 수정 시 가능 응답 초기화. 저장 후 재확인. 기존 확정 출연은 예약을 유지하며 재확인 표시 | SORA → 부킹 수정 → 시간 변경 → 아티스트 화면 미리보기 |
| 출연 구간만 겹침 검사 | 출연 후 교체 시간, 다음 행사 이동 시간 포함. 같은 베뉴의 다른 행사라도 같은 무대 확인 | 부킹 수정 → 교체·이동 여유 시간 |
| 자료 URL 등록과 운영팀 검토를 구분할 수 없음 | 자료 등록·운영팀 검토·아티스트 확인을 분리. 자료 수정 시 두 확인 초기화. 시간만 바뀌면 자료 검토 유지 | 부킹 → 자료 검토 / 아티스트 화면 미리보기 |
| 취소 후 링크·게스트 영향이 안내 문구에만 있음 | 사유 입력, 연결 링크의 등록/입장 인원 확인, 링크 상태 유지/추가 등록 중지 선택. 다른 확정 부킹의 공용 링크 중지 차단 | 부킹 → 부킹 취소 |
| 링크 관리로 이동한 뒤 해당 링크를 다시 찾아야 함 | 연결된 링크 상세를 직접 열고 취소 후에도 접근 유지 | 부킹 → 연결된 게스트 링크 |

부킹 상태·자료 검토·업무 완료는 별도 상태다. 자료 검토를 눌러도 아티스트가 응답한 것으로 기록하지 않는다. 같은 자료 URL의 원격 파일 내용 변경은 감지하지 않으므로 실제 제품에서는 파일/자료 버전 계약이 필요하다.

## 남은 설계 범위

- **아티스트 식별 연결:** 현재 Artist ID와 기존 개인 계정/Contributor를 자동 병합하지 않는다. 동일인 연결은 명시적인 계정 선택·검증과 과거 게스트 집계 정책을 정한 뒤 다룬다. 이름·이메일 유사성만으로 합치지 않는다.
- **실제 외부 협업:** 지금의 아티스트 화면은 관리자가 조작하는 모의 미리보기다. 초대·본인 확인·위임 권한·응답 만료·발송/수신 상태는 후속 제품 구현이다.
- **전체 일정 자원:** 버퍼 충돌은 현재 베뉴에서 관리하는 출연에 한정한다. 외부 베뉴 일정, 이동 경로, 사운드체크/리허설의 종료 시간과 자원 점유, 복수 후보의 홀드 우선순위는 추가 설계가 필요하다.
- **행사 변경·현장 인계:** 행사 날짜 변경/종료에 따른 모든 부킹의 일괄 재조율, 대체 출연자 연결, 현장 담당자 연락망·최종 진행표 배포·수신 확인은 후속이다. 이번에는 종료 행사에 남은 확정 부킹을 확인 대상으로 표시한다.
- **반복 행사:** 이전 부킹의 행사 자료·상대 응답·업무 완료를 무조건 복사하지 않는다. 현재 재부킹은 아티스트 프로필 기본 자료로 새 문의를 만든다.

결제·비용·정산은 이번 파이프라인 범위에 포함하지 않는다.
