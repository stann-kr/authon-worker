# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 항목은 일자 단위이며 최신 항목을 위에 둔다. 파일 단위 세부 구현 이력은 공개 문서에 포함하지 않는다.

## 2026-08-07

### 이관 계정 최초 로그인 복구

#### Fixed

- 비밀번호를 아직 설정하지 않은 이관 계정이 최초 로그인에서 임의의 비밀번호를 입력하면 오류 대신 새 비밀번호 설정 단계로 이동하도록 복구했다.
- 관리자 생성·재설정 계정은 기존과 같이 발급된 1회용 설정 코드가 일치할 때만 설정 단계에 진입하도록 구분했다.

## 2026-08-05

### 모바일 관리자 메뉴 위치 안정화

#### Fixed

- 모바일에서 관리자 업무 메뉴를 선택할 때 작업 영역으로 강제 스크롤되어 상단 메뉴가 고정 header 뒤로 사라지던 문제를 수정했다.
- 선택된 메뉴 링크와 현재 scroll 위치를 유지하고, 같은 업무를 다시 선택해 중복 browser history가 쌓이지 않도록 했다.
- 화면 위치를 강제로 바꾸지 않아도 보조 기술이 바뀐 업무명을 알 수 있도록 현재 작업을 live status로 전달한다.

### 모바일 홈 카드와 내비게이션 정리

#### Changed

- 모바일 홈 카드에서 아이콘과 제목을 한 행에 두고 설명은 카드 전체 폭을 사용하도록 재배치해 메뉴마다 줄바꿈과 작업 진입선이 어긋나지 않게 했다.
- 홈 카드 설명을 각 업무의 핵심 행동만 남기도록 줄이고, 작은 화면에서는 카드 높이가 내용에 맞춰 자연스럽게 결정되도록 조정했다.
- 모바일 고정 하단 전역 navigation을 제거하고 상단 브랜드를 홈 진입점으로 유지해 콘텐츠를 가리지 않는 단순한 이동 구조로 바꿨다.

#### Fixed

- 하단 navigation 제거 뒤에도 본문 예약 여백과 관리 링크 작업 알림의 높은 하단 위치가 남지 않도록 safe area 기준을 정리했다.

### 운영 화면 의미 구조와 상태 피드백 개선

#### Changed

- 이동 action과 실행 action을 각각 링크와 버튼으로 구분하면서 같은 크기·색상·눌림 피드백을 사용하도록 인증·관리 화면의 작업 control을 통일했다.
- 로그인·비밀번호·프로필과 운영 입력에 브라우저 자동 완성 목적을 명확히 하고, 모바일 전역 navigation과 Admin 업무 label을 최소 12px로 조정했다.
- 사용자·베뉴·링크처럼 사람이 읽는 이름과 안내 문장은 sans-serif sentence case를 기본으로 정리하고 숫자·URL·짧은 상태에만 mono 표현을 유지했다.
- 게스트 추가 패널의 남은 인원을 전체 한도와 함께 정식 panel header에 배치하고, header 하단 경계를 정원 사용률 상태선으로 공유해 별도 위젯처럼 보이지 않도록 통합했다.
- 홈 작업 카드는 업무 분류, 구체적 메뉴명, 한 줄 설명과 진입 action을 한 번씩 제공하고 세 메뉴를 한 줄에 배치해 빈 프레임처럼 보이거나 카드 하나가 홀로 남는 문제를 줄였다.

#### Fixed

- 비밀번호 재설정 단계가 순서와 현재 단계를 보조 기술에 전달하고, 정책·확인 오류가 실제 관련 입력에만 연결되며 해당 입력으로 focus가 이동하도록 수정했다.
- 프로필 비밀번호 변경에서도 한 입력의 오류가 모든 비밀번호 입력을 잘못 표시하지 않도록 오류 범위를 분리했다.
- 목록 최초 조회 중 실제 값처럼 `0`을 표시하던 count를 준비 상태로 바꾸고, 관리 작업의 제각각인 spinner와 생략 부호를 일관된 label 유지형 진행 표시로 교체했다.
- 비밀번호 재설정 완료 화면에서 같은 로그인 이동 action이 중복 표시되던 문제를 수정했다.

### 게스트 작업 버튼과 추가 카드 정리

#### Changed

- 로그인 사용자와 외부 링크의 게스트 추가 카드에서 단건 입력과 여러 이름 붙여넣기를 반복 안내하던 설명문을 제거했다.

#### Fixed

- 입장 확인 버튼의 semantic 색상을 버튼 variant에 직접 연결해 실행 중인 개발 서버에서 배경색만 누락되고 텍스트가 보이지 않던 문제를 수정했다.

### 홈 메뉴 카드 비율과 위계 복원

#### Fixed

- 홈 메뉴 카드가 짧은 가로 행처럼 보이던 분할형 shortcut rail을 제거하고, 아이콘·단축키·메뉴명·이동 방향을 하나의 큰 카드 표면 안에서 읽도록 정리했다.
- 권한에 따라 메뉴가 1~2개만 표시될 때 카드가 본문 전체 폭으로 과도하게 늘어나지 않도록 카드 폭을 안정화했다.

### 목록 헤더 작업 순서 개선

#### Changed

- Door 게스트 목록의 작업 순서를 정렬, 입장 대기 우선, 새로고침 순으로 조정해 새로고침을 헤더의 가장 오른쪽에 배치했다.

### 홈 작업 카드와 헤더 정렬 개선

#### Changed

- 홈 작업 메뉴를 헤더의 브랜드와 작업 버튼 사이 콘텐츠 축에 맞춰 넓히고, 다른 운영 화면과 같은 본문 폭을 사용하도록 통일했다.
- 메뉴 카드를 각각 구분되는 패널로 재구성하고, 태블릿에서는 2열로 배치해 아이콘, 메뉴명과 이동 방향을 더 빠르게 구분할 수 있도록 개선했다.

### 모바일 게스트 행 작업 정렬 개선

#### Changed

- 모바일 게스트 목록의 입장 확인·취소·삭제 작업을 데스크톱과 같은 행 우측에 배치하고, 버튼이 목록 전체 폭을 차지하지 않도록 조정했다.
- 반복되는 입장 확인 버튼은 순백색보다 한 단계 낮은 밝은 회색을 사용해 어두운 화면에서의 눈부심을 줄였다.

### 날짜 전환 중 추가 게스트 요청 안정화

#### Fixed

- Guest 화면에서 운영 날짜를 바꿀 때 추가 게스트 요청 영역이 잠깐 사라졌다 다시 나타나던 문제를 수정했다.
- 같은 운영 날짜의 게스트·한도 상태만 전환 중에 보존하고, 한도 조회가 부분적으로 실패해도 기존 요청 상태가 불필요하게 사라지지 않도록 보완했다.

### 운영 UI 정렬과 상호작용 개선

#### Added

- Door 명단에 `입장 대기 우선` 선택을 추가했다. 기본값은 대기 명단 우선이며, 끄면 입장 확인 뒤에도 등록 순서를 유지하고 선택 상태를 같은 브라우저에 보존한다.

#### Changed

- 홈 작업 공간을 Guest, Door, Admin 고정 순서의 큰 카드로 복원하고 화면 순서, 표시 번호와 숫자 단축키를 일치시켰다.
- 게스트 단건 추가, 여러 이름 붙여넣기와 추가 인원 요청을 같은 패널·확장 규칙으로 통일하고 남은 인원을 제목 기준선에 정렬했다. 붙여넣기 예시는 실제 이름 대신 중립적인 표기로 바꿨다.
- 사용자·게스트 현황 수치는 중첩 구획선 대신 간격이 있는 단일 surface tile로 단순화하고, 게스트 행의 배경을 안정적인 한 톤으로 정리했다.
- 버튼, 업무 navigation, disclosure, dialog와 skeleton에 짧은 상호작용 motion을 추가하고 reduced-motion 환경에서는 transform 효과를 제거했다.

#### Fixed

- Admin 좌측 업무 navigation과 오른쪽 작업 영역의 상단 시작점이 화면별로 어긋나던 문제를 수정했다.
- 화면 전환 뒤 메인 영역 focus가 페이지를 자동으로 밀어 올리던 문제와 비상호작용 영역에 큰 기본 외곽선이 나타나던 문제를 수정했다.
- 모바일 footer가 하단 전역 navigation을 가리거나 마지막 콘텐츠가 navigation 아래에 숨을 수 있던 문제를 수정했다.
- 추가 게스트 요청 중 예외가 발생하면 제출 상태가 남던 문제와 확인 dialog를 취소한 뒤 다시 열 수 없거나 종료 중 다른 action이 실행될 수 있던 문제를 수정했다.

### CRM형 운영 대시보드 구조 개선

#### Added

- 권한에 맞는 mobile 전역 navigation과 Admin 업무별 direct link를 추가해 현재 화면에서 다른 운영 업무로 바로 이동할 수 있다.
- 베뉴 목록을 불러오지 못한 화면에서 오류를 숨기지 않고 해당 영역에서 다시 시도할 수 있다.

#### Changed

- Admin을 desktop 고정 sidebar와 mobile 전체 업무 목록을 갖춘 CRM형 구조로 바꾸고, 하위 화면의 중복 section navigation과 장황한 작업 설명을 정리했다.
- 홈은 Guest, Door, Admin 이름만 남긴 간결한 작업 행으로 축소하고 역할에 맞는 기본 업무를 먼저 배치한다.
- Guest, Door, Admin, Profile을 공통 workspace shell로 통합하고 기존 상단 header의 간결한 구성을 유지하면서 320px 화면, mobile safe area, 44px touch target에 맞춰 목록과 작업 control을 재배치했다.
- 눌림, dialog 진입과 disclosure에만 짧은 motion을 사용하고 reduced-motion 환경에서는 transform 효과를 제거했다.

#### Fixed

- 확인 dialog의 focus trap, 본문 접근 차단, Escape 닫기와 trigger focus 복귀를 보강했다.
- route 전환 중 이전 화면에 focus가 남는 문제와 상단·하단 고정 navigation이 mobile 콘텐츠를 가릴 수 있는 문제를 수정했다.

### 여러 이름 붙여넣기 UI 정리

#### Changed

- 여러 이름 붙여넣기를 게스트 추가 패널 안의 평평한 확장 섹션으로 정리해 중첩 카드처럼 보이던 시각적 위계를 제거했다.
- 입력 안내와 미리보기 구획, 보조 작업의 강조 수준을 기존 폼과 맞추고 모바일에서는 명단이 페이지 흐름을 따라 자연스럽게 이어지도록 개선했다.

### 로컬 테스트 로그인 안정화

#### Changed

- 로컬 테스트 데이터 seed는 설정된 공통 비밀번호를 재사용하며, 명시적으로 전달한 값과 로컬 설정이 다르면 데이터 변경 전에 중단한다.
- seed 결과에서 평문 비밀번호를 출력하지 않고, 명시된 로컬 설정 없이 임의 비밀번호를 생성하지 않는다.

#### Fixed

- 로컬 HTTP 개발 주소에서 인증 쿠키가 저장되지 않아 로그인 직후 다시 로그인 화면으로 돌아가던 문제를 수정했다. HTTPS와 외부 주소의 인증 쿠키는 기존처럼 `Secure` 속성을 유지한다.

### 게스트 대량 등록과 외부 링크 재사용 개선

#### Added

- 로그인 게스트 화면과 외부 게스트 링크에서 한 줄에 한 명씩 최대 25명을 붙여넣고, 정규화·중복·유효성·남은 정원을 미리 확인한 뒤 등록할 수 있다.
- 외부 링크 관리에서 기존 링크의 DJ·이벤트·정원·언어 설정을 새 날짜의 템플릿으로 불러오고, 새 token과 URL을 발급할 수 있다.
- 지원 환경에서는 시스템 공유 화면으로 외부 링크를 전달하고, 지원하지 않거나 공유에 실패하면 URL 복사로 전환한다.

#### Changed

- 일반 게스트 작업 공간은 현재 계정이 등록한 명단만 반환하고, 베뉴 전체 명단 조회는 Door 또는 Admin 접근 권한이 있는 화면으로 제한한다.
- 게스트 이름과 외부 링크 생성 필드를 서버에서도 정규화·검증하고, 잘못된 필드는 입력 가까이에서 안내한다.
- 단건 등록에서도 이미 존재하는 이름은 자동으로 다시 넣지 않으며, 중복 등록은 대량 입력 미리보기에서 명시적으로 확인하도록 통일했다.

#### Fixed

- 동시 대량 등록에서도 계정 한도와 외부 링크 정원을 원자적으로 적용하고, 중복 후보나 변경된 정원은 입력란에 남겨 다시 확인할 수 있도록 했다.
- 외부 링크 게스트의 반복 삭제·영구 삭제가 사용 인원을 중복 차감하지 않으며, 삭제된 게스트를 상태 변경으로 되살려 정원을 우회할 수 없도록 했다.
- 게스트 삭제와 상태 변경의 실제 쓰기 조건에도 예상 베뉴와 소유권을 적용해 권한 확인 직후 범위가 바뀌는 경우 작업을 중단한다.
- 외부 링크의 일시적인 조회 장애를 만료·비활성 링크와 구분하고, 쓰기 직후 최신 명단을 확인하지 못하면 입력을 보존한 채 등록·삭제를 잠그고 재시도를 제공한다.

#### Security

- 공개 링크의 게스트 등록 요청에 링크·요청자 기준의 보조 rate limit을 적용하고, 최종 정원 판정은 D1 원자 조건으로 유지한다.
- 이름과 링크 입력에서 위험한 제어·방향 전환·숨은 문자를 거부하고, 오류 미리보기에도 해당 문자를 그대로 렌더링하지 않는다.
- Door·Admin 명단에는 외부 기여자 식별에 필요한 이름과 내부 ID만 반환하고, token과 공개 URL을 포함한 링크 credential 조회는 관리자 링크 관리 기능으로 제한한다.
- 외부 token 삭제는 실제 쓰기 시점의 token·베뉴·활성·보관·만료·운영일과 입장 대기 상태를 한 번 더 확인해, 권한 철회 뒤 삭제나 체크인 기록 제거를 차단한다.
