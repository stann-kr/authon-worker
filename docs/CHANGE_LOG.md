# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 항목은 일자 단위이며 최신 항목을 위에 둔다. 파일 단위 세부 구현 이력은 공개 문서에 포함하지 않는다.

## Unreleased

### Docs

- 공개 문서 범위를 README, 기술 명세, 변경 이력, 재발 가능한 트러블슈팅으로 정리했다.
- 내부 전환 계획, remediation checklist, deployment runbook은 비공개 문서 레이어로 분리했다.
- 변경 이력과 트러블슈팅의 날짜·항목 헤딩을 최신 문서 구조에 맞춰 정리했다.

## 2026-08-03

### Supabase 운영 데이터 D1 이전 도구 보강

#### Changed

- Supabase의 새 Secret API key와 레거시 service role key를 모두 사용해 운영 데이터 snapshot을 내보낼 수 있도록 호환성을 보강했다.
- 외부 링크의 사용 인원을 비삭제 게스트 행에서 다시 계산해 원본 카운터 드리프트가 D1으로 전파되지 않도록 했다.

#### Security

- snapshot 검증 결과에서 외부 링크 token 원문이 출력되지 않도록 정리했다.

## 2026-07-27

### 운영 데이터 이전 준비, 빌드 복구, 보안 감사

#### Added

- 운영 데이터의 D1 이전을 위해 legacy user id와 migration 상태를 추적하는 사용자 메타데이터와 조회 인덱스를 추가했다.
- 운영 데이터 snapshot을 export·검증하고 D1 import SQL과 reset link 산출물을 생성하는 보조 흐름을 마련했다.
- 홈과 admin 화면에 키보드 단축키, 영업일 기준 빠른 날짜 이동, 운영 상태 badge, 홈 복귀 동선을 추가했다.

#### Changed

- Next.js 16의 proxy 방식이 현재 Worker 빌드 조합에서 지원되지 않아, 인증·세션·RBAC 검증을 단일 middleware 흐름으로 유지하도록 정리했다.
- 기존 사용자 전환 방식을 reset link 기반 onboarding으로 정리했다.
- lint, type check, app build, Worker build로 이어지는 검증 흐름을 정비했다.
- tab UI의 ARIA 속성, 아이콘 버튼 라벨, 전역 focus-visible 스타일을 보강했다.

#### Security

- reset-password token 원문 저장을 중단하고 hash 기반 저장으로 전환했다.
- 로그인 실패 응답을 단일 메시지로 통일해 계정 존재 여부 노출을 완화했다.
- 서버 액션의 내부 오류 메시지가 클라이언트로 직접 반환되지 않도록 공개 메시지와 서버 로그를 분리했다.
- 내부 동기화 엔드포인트의 shared secret 비교를 timing-safe 방식으로 바꾸고 payload 검증을 추가했다.
- 응답 보안 헤더(CSP, Referrer-Policy, X-Content-Type-Options, X-Frame-Options, Permissions-Policy)를 추가했다.
- 비-super-admin의 venue scope와 role 생성 제한을 보강했다.
- production dependency 취약점을 해소했다.

## 2026-05-22

### 마이그레이션 사후 보안 점검 및 품질 개선

#### Security

- 모든 Server Action에 공통 인증·권한 검증을 적용했다.
- 로그아웃 이후 JWT 재사용을 막기 위해 세션 저장소 존재 여부를 함께 확인하도록 했다.
- 이메일 존재 여부 노출 완화, fallback password 제거, 외부 링크 소유권 검증, 비밀번호 강도 검증을 반영했다.
- 외부 링크 정원 확인과 증가를 원자적 갱신으로 바꿔 동시 요청 시 정원 초과를 막았다.
- 비밀번호 재설정 처리를 원자적으로 수행하도록 정리했다.
- 비밀번호 해시를 WebCrypto PBKDF2 기준으로 전환하고 기존 해시는 로그인 시 점진 전환하도록 했다.
- 환경 변수 접근을 요청 스코프 런타임 바인딩으로 통일하고 쿠키 보안 속성을 항상 적용했다.

#### Added

- 조회 성능을 위한 D1 인덱스를 추가했다.
- 공통 DB client helper를 추가했다.

#### Fixed

- 로그인 응답에 누락되어 있던 사용자 속성을 포함하도록 했다.
- 마이그레이션 경로에서 이메일 발송 실패가 사용자 생성 결과에 영향을 주지 않도록 분리했다.
- 내부 API secret 미설정 시 엔드포인트를 비활성화하도록 했다.
- 이미 삭제된 게스트의 재삭제로 사용량이 이중 차감되는 문제를 방어했다.

#### Changed

- 게스트 목록 폴링을 공통 훅으로 통일하고, 광범위한 `any` 사용과 불안정한 타입 캐스팅을 줄였다.
- 민감 정보가 포함될 수 있는 로컬 샘플 데이터를 정리했다.
